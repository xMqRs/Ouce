# Capas automáticas do Ouce

Quando alguém adiciona uma música que não tem capa embutida, o Ouce sorteia uma imagem ou GIF desta pasta.

Para incluir uma nova capa:

1. Coloque o arquivo (`.gif`, `.jpg`, `.png` ou `.webp`) nesta pasta. Nome só com letras, números, `-`, `_` e `.`.
2. Adicione uma linha em `covers.json`: `{ "file": "nome.gif" }`.

Dica: use imagens em 16:9 ou quadradas, de preferência abaixo de 3 MB. Use só artes que você tem permissão para usar.
